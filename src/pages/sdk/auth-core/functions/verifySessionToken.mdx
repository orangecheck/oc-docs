# Function: verifySessionToken()

```ts
function verifySessionToken(token: string, cfg: VerifyConfig): Promise<SessionPayload | null>;
```

Defined in: [index.ts:514](https://github.com/orangecheck/oc-packages/blob/main/auth-core/src/index.ts#L514)

Crypto-only JWT verify. Returns the payload on success, `null` on
any failure (bad signature, expired, wrong issuer, malformed).

Safe for consumer subdomains — they only need the public JWK. A signed-out
token still verifies here; pass the payload to
[familyRevocationCheck](familyRevocationCheck) to refuse it.
