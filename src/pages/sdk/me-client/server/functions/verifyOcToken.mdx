# Function: verifyOcToken()

```ts
function verifyOcToken(token: string, options?: VerifyOcTokenOptions): Promise<SessionPayload | null>;
```

Defined in: [me-client/src/server.ts:151](https://github.com/orangecheck/oc-packages/blob/main/me-client/src/server.ts#L151)

Verify a sign-in token: the signature, the issuer, expiry and, with
`audience`, that it was issued to your site. A token bound to your site with
no revocation handle is refused (see [VerifyOcTokenOptions.requireHandle](../interfaces/VerifyOcTokenOptions#property-requirehandle)).
Null for any token that fails. It does not read the list of ended sessions:
`getOcSession` and the adapters do.
