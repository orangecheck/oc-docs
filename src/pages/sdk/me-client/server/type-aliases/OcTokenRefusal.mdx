# Type Alias: OcTokenRefusal

```ts
type OcTokenRefusal = 
  | OcSessionRefusal
  | "audience"
  | "insufficient_authentication";
```

Defined in: [me-client/src/server.ts:99](https://github.com/orangecheck/oc-packages/blob/main/me-client/src/server.ts#L99)

Why [checkOcToken](../functions/checkOcToken) refuses a token, when it can say: an
[OcSessionRefusal](OcSessionRefusal); `audience`: the token is genuine but was made for
another site (check that `audience` is your origin exactly, scheme and port
included); or `insufficient_authentication`: the token is genuine and for
this site, but its sign-in does not meet `requireSignIn`, an option
`@orangecheck/auth-core` reads from 2.35.0.
