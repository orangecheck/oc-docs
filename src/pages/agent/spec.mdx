## Delegation canonical message (§SPEC 4.1)

```
oc-agent:delegation:v1
principal: <btc_address>
agent: <btc_address>
scopes: <scope_1>,<scope_2>,…
bond_sats: <non-negative integer>
bond_attestation: <64-hex | "none">
issued_at: <ISO 8601 UTC>
expires_at: <ISO 8601 UTC>
nonce: <32-hex>
```

Each line LF-terminated; no trailing LF after `nonce`. Scopes are serialized in
**sorted order** (lexicographic byte order) and joined by a single ASCII comma.
Envelope id = `sha256(canonical_message_bytes)` rendered as lowercase hex.

A delegation lasts at most 365 days: `expires_at - issued_at` is at most
31,536,000 seconds (§SPEC 4.4). A longer one is malformed whatever the clock
says.

## Agent-action canonical message (§SPEC 5.1)

```
oc-agent:action:v1
address: <agent_btc_address>
content_hash: sha256:<64-hex>
content_length: <positive integer>
content_mime: <RFC 6838 media type>
signed_at: <ISO 8601 UTC>
delegation_id: <64-hex>
scope_exercised: <scope string>
```

A strict extension of OC Stamp's canonical message. OC Stamp verifiers that
treat unknown-field additions tolerantly (as the spec requires) correctly verify
authorship and priority; authority verification is additive.

## Revocation canonical message (§SPEC 9.1)

```
oc-agent:revocation:v1
address: <signer_btc_address>
delegation_id: <64-hex>
reason: <ASCII, max 128 bytes, "" if omitted>
signed_at: <ISO 8601 UTC>
```

## Signing

All three envelopes sign the **hex-encoded ASCII id** (64 bytes) via BIP-322
under the appropriate signer's Bitcoin address:

- Delegation → principal's address.
- Agent-action → agent's address.
- Revocation → the delegation's principal or agent. Either may always revoke
  (SPEC §9.5); `revocation.holders` decides nothing.

## Scope grammar

See [scope grammar](/agent/scopes) for the detailed walkthrough.

```
scope         := product ":" verb [ "(" constraint-list ")" ]
constraint    := key op value
op            := "=" | "!=" | "<" | "<=" | ">" | ">=" | "*"
```

Registry: `lock:seal`, `lock:chat`, `stamp:sign`, `vote:cast`, `nostr:publish`,
`http:request`, `ln:send`, `mcp:invoke`, `pledge:create`, and the adapter scopes
`anthropic:tool`, `openai:function`, `vercel:tool` and `langgraph:tool`. Keys
per scope are on [Scopes](/agent/scopes).

## Verification algorithm (§SPEC 8)

Verification runs at a time, `now`. **Live verification** decides whether to act
on `A` now, and is what the steps below mean. An **audit** checks a past action
as of its own `A.signed_at` (below). A verifier deciding whether to act MUST
verify live.

```
verify(D):
  1. v == 1 else E_UNSUPPORTED_VERSION
  2. shape check, incl. issued_at < expires_at ≤ issued_at + 365 days, else E_MALFORMED
  3. reconstruct canonical → id' == D.id else E_BAD_ID
  4. scopes parse + validate else E_BAD_SCOPE_GRAMMAR
  5. BIP-322(D.principal, D.id) verifies else E_BAD_SIG
  6. now ∈ [issued_at, expires_at), for D and every link of a chain,
     else E_NOT_YET_VALID / E_EXPIRED
  7. no revocation targeting D.id in effect at or before now, and none
     effective before A.signed_at, else E_REVOKED

verify(A, D):
  8. verify(D) clean, at now
  9. base stamp checks on A else E_BAD_ACTION_STAMP
 10. A.delegation_id == D.id else E_DELEGATION_MISMATCH
 11. A.signer.address == D.agent.address else E_AGENT_MISMATCH
 12. A.signed_at ∈ [D.issued_at, D.expires_at) else E_OUT_OF_WINDOW
 12a. |now − A.signed_at| ≤ the verifier's bound (120 s recommended) else E_STALE
 12b. act on each A.id once: keep accepted ids until A.signed_at + the bound
 13. A.scope_exercised ⊆ some scope in D.scopes else E_SCOPE_DENIED

optional bond check:
 14. D.bond non-null else E_NO_BOND
 15. D.bond.sats >= threshold else E_BOND_UNMET
 16. resolve(D.bond.attestation_id) still valid else E_BOND_UNVERIFIED
```

`A.signed_at` is chosen by the agent. Live, steps 6, 7 and 12a make it
irrelevant to whether the delegation is in force or revoked. An **audit** (§SPEC
8.6) skips steps 6, 12a and 12b, refuses only a revocation effective before
`A.signed_at`, and MUST report that time as the agent's claim unless a checked
OTS anchor fixes it. An audit never decides whether to act now. In
`@orangecheck/agent-core`, `verifyAction` is the live check and
`verifyActionAsOfSignedAt` the audit.

## Error codes (§SPEC 11)

`E_UNSUPPORTED_VERSION` · `E_MALFORMED` · `E_BAD_ID` · `E_BAD_SIG` ·
`E_BAD_SCOPE_GRAMMAR` · `E_NOT_YET_VALID` · `E_EXPIRED` · `E_REVOKED` ·

[private scope](/agent/private-scope) for the confidential-mode verifier
extension.

## Canonicalization (§SPEC 6)

- RFC 8785 JSON canonicalization (lexicographic key sort; no insignificant
  whitespace; `\uXXXX` only for control chars and `"` / `\`).
- Arrays preserve order **except** the top-level `scopes` field of a delegation,
  which MUST be sorted lexicographically to match the canonical-message
  serialization.
- Constraints within a scope string MUST be sorted by key for canonical form.

## Versioning

`envelope.v` is an integer. Future incompatible changes increment it.
Unknown-field tolerance handles minor additions.
