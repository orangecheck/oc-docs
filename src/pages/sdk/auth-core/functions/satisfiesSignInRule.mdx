Defined in: [sign-in.ts:85](https://github.com/orangecheck/oc-packages/blob/main/auth-core/src/sign-in.ts#L85)

Whether a token's sign-in meets `requirement` at `now`, in Unix seconds. A
fact the token does not state meets nothing, so a token minted before the
facts were written meets only an empty requirement. Throws on a
requirement [parseSignInRequirement](parseSignInRequirement) refuses, or a `now` that is not a
finite number.
